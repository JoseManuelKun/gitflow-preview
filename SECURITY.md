# Security Policy

## Supported Versions

GitFlow Preview is a documentation project. Security updates apply to the current published documentation and repository configuration.

| Version | Supported |
| --- | --- |
| Current `master` | Yes |
| Older branches or forks | No |

## Reporting a Vulnerability

If you find a security issue related to repository automation, CI/CD examples, deployment guidance, or documentation that could cause unsafe behavior, please report it privately to the maintainers.

Do not open a public issue for sensitive vulnerabilities.

When reporting, include:

- A clear description of the issue.
- Affected files or workflow examples.
- Steps to reproduce or validate the concern.
- Suggested mitigation, if available.

## Scope

Security reports may include:

- Unsafe CI/CD examples.
- Insecure deployment guidance.
- Branch protection bypass concerns.
- Secrets handling issues in example workflows.
- Documentation that could encourage unsafe production deployment.

## Response

Maintainers SHOULD acknowledge security reports as soon as reasonably possible and prioritize fixes that affect production safety, branch protection, or credential handling.
