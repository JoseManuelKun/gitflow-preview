# Code of Conduct

## Our Pledge

We pledge to make participation in GitFlow Preview a respectful and productive experience for everyone.

## Expected Behavior

Contributors are expected to:

- Use welcoming and inclusive language.
- Respect different viewpoints and experience levels.
- Give and receive constructive feedback.
- Focus discussions on the project, workflow, and documentation quality.
- Help maintain a professional environment.

## Unacceptable Behavior

Unacceptable behavior includes:

- Harassment, intimidation, or discriminatory language.
- Personal attacks.
- Deliberate disruption of project discussions.
- Publishing private information without permission.
- Any conduct that maintainers reasonably consider inappropriate.

## Enforcement

Maintainers may remove comments, reject contributions, or restrict participation when behavior violates this Code of Conduct.

## Reporting

To report a concern, contact the project maintainers through the repository issue tracker or the security contact listed in `SECURITY.md` when the concern is security-sensitive.
